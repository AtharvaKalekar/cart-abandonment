# Cart Abandonment Analysis (Case Study 59)

1. Put `online_shoppers_intention.csv` in `data/raw/` (UCI dataset id 468).
2. `pip install -r requirements.txt`
3. Open `notebooks/Cart_Abandonment_Analysis.ipynb` and run all cells top to bottom (about 20 to 30 minutes).
   The last section writes `models/`, `reports/` and `reports/figures/`.
4. `streamlit run app/streamlit_app.py`
